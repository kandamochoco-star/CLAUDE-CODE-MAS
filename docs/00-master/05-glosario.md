# Glosario de terminología del proyecto El Tablazo

## A — Energía y generación

| Término | Significado |
|---|---|
| **BESS** | Battery Energy Storage System. Sistema de almacenamiento por baterías electroquímicas. |
| **BOP** | Balance of Plant. Equipos auxiliares de una planta de generación (bombas, tuberías, tableros, etc.). |
| **CCGT** | Combined Cycle Gas Turbine. Ciclo combinado: turbina de gas + recuperador de calor + turbina de vapor. |
| **Cogeneración** | Generación simultánea de electricidad + calor útil (vs. ciclo abierto que desperdicia el calor). |
| **DCS** | Distributed Control System. Sistema de control de planta distribuido (Emerson Ovation, ABB 800xA). |
| **ERM** | Estación de Regulación y Medición de gas. Reduce presión y mide entrega del gasoducto. |
| **GFM** | Grid-Forming Inverter. Inversor capaz de operar en isla formando la red por sí mismo. |
| **GIS** | Gas Insulated Switchgear. Subestación con aislamiento en gas SF₆ (alternativa AIS = aire). |
| **HRSG** | Heat Recovery Steam Generator. Caldera que recupera calor de gases de escape para producir vapor. |
| **HVO** | Hydrotreated Vegetable Oil. Diesel renovable de aceites vegetales hidrotratados (90% menos CO₂ que diesel fósil). |
| **LCOE** | Levelized Cost of Energy. Costo nivelado por kWh que incluye CAPEX, OPEX, fuel y vida útil. |
| **LFP** | LiFePO₄. Química de batería litio-ferrofosfato (más segura, menos densa que NMC). |
| **LM6000** | Aeroderivative gas turbine de GE Vernova, clase 50–60 MW, derivada del motor CF6 aviación. |
| **MMBtu** | Million British Thermal Units. Unidad estándar de gas natural (1 MMBtu ≈ 0,293 MWh térmicos). |
| **PCS** | Power Conversion System. Inversores + transformador del BESS para conectar a la red. |
| **PEM** | Proton Exchange Membrane. Tipo de electrolizador para producir H₂ verde (rápido respuesta, costoso). |
| **PPA** | Power Purchase Agreement. Contrato bilateral de venta de energía a largo plazo. |
| **PUE** | Power Usage Effectiveness. Total energía DC ÷ energía TI. Tier IV objetivo < 1,4; world-class < 1,2. |
| **SCR** | Selective Catalytic Reduction. Sistema de tratamiento de NOx en gases de escape (urea + catalizador). |
| **SIN** | Sistema Interconectado Nacional. Red eléctrica unificada de Colombia operada por XM. |
| **STG** | Steam Turbine Generator. Turbogenerador de vapor. |
| **UPS** | Uninterruptible Power Supply. Estático (electrónico) o rotativo (volante de inercia + diesel). |

## B — Hidrógeno

| Término | Significado |
|---|---|
| **H₂ verde** | Hidrógeno producido por electrólisis con energía 100% renovable. ~$4–8/kg en 2025. |
| **H₂ azul** | Hidrógeno de gas natural con captura y secuestro de CO₂ (CCS). ~$2–4/kg. |
| **H₂ gris** | Hidrógeno de reformado de gas natural sin captura (la mayoría hoy). ~$1–2/kg. |
| **DLE H₂-ready** | Dry Low Emissions burner certificado para mezclas de H₂ hasta cierto %. |

## C — Data Center

| Término | Significado |
|---|---|
| **Colocation** | Modelo de negocio: el operador renta espacio + energía + cooling. El cliente trae sus propios servidores. |
| **CRAH** | Computer Room Air Handler. Manejadora de aire para sala TI con agua helada. |
| **DCIM** | Data Center Infrastructure Management. Software de gestión integral del DC (Schneider EcoStruxure, Vertiv Trellis). |
| **DLC** | Direct Liquid Cooling. Refrigeración por líquido directo al chip (cold-plate o inmersión). |
| **Hyperscale** | Data center de muy gran escala (>50 MW), normalmente para Big Tech. |
| **MMR** | Meet-Me Room. Sala donde los carriers de telco interconectan fibras con clientes del DC. |
| **NOC** | Network Operations Center. Sala de operación de red e infraestructura. |
| **RDHX** | Rear Door Heat Exchanger. Puerta trasera de rack con intercambiador de calor agua. |
| **Tier IV / Rated-4** | Máximo nivel de redundancia (Uptime Institute / TIA-942-C). 2N+1, tolerancia a fallo único, 99,995% disponibilidad. |
| **WUE** | Water Usage Effectiveness. Litros de agua / kWh de TI. World-class < 0,3 L/kWh. |
| **CUE** | Carbon Usage Effectiveness. kg CO₂ / kWh de TI. |
| **ERE** | Energy Reuse Effectiveness. Mide cuánto calor residual se reutiliza (>0 mejor). |

## D — Seguridad

| Término | Significado |
|---|---|
| **GSOC** | Global Security Operations Center. Centro de mando de seguridad física integral. |
| **SOC (cyber)** | Security Operations Center. Centro de operaciones ciber (detección + respuesta). |
| **SCIF** | Sensitive Compartmented Information Facility. Sala blindada para información clasificada (ICD-705). |
| **TEMPEST** | Estándar NSA para protección contra emanaciones electromagnéticas comprometedoras. |
| **NIST 800-53** | Catálogo de controles de seguridad federal USA (HIGH = más exigente). |
| **K8 / K12 / M50** | Clasificaciones ASTM F2656 de barreras anti-vehículo (K12 detiene camión 6,8 t a 80 km/h). |
| **Blast-resistant GSA 3a/3b** | Vidrios resistentes a explosiones según General Services Administration USA. |
| **Mantrap** | Esclusa con dos puertas en serie: una abre sólo al cerrar la otra. |
| **PSIM** | Physical Security Information Management. Software integrador de cámaras + accesos + alarmas. |
| **VESDA** | Very Early Smoke Detection Apparatus. Detección de humo por aspiración. |
| **CPNI** | Centre for the Protection of National Infrastructure (UK). Buenas prácticas de seguridad perimetral. |

## E — Aviación

| Término | Significado |
|---|---|
| **Aerocivil / UAEAC** | Unidad Administrativa Especial de Aeronáutica Civil de Colombia. Regulador. |
| **Airplan** | Concesionario operador del aeropuerto JMC. |
| **JMC / MDE** | Aeropuerto Internacional José María Córdova de Rionegro (código IATA: MDE). |
| **OLS** | Obstacle Limitation Surfaces. Superficies imaginarias que limitan altura cerca de aeródromos. |
| **RAC** | Reglamento Aeronáutico Colombiano (RAC 14 = aeródromos, RAC 154 = diseño). |
| **FATO** | Final Approach and Take-Off Area. Superficie final de aproximación y despegue de helicóptero. |
| **TLOF** | Touchdown and Lift-Off Area. Zona de aterrizaje y despegue de helicóptero. |
| **VFR** | Visual Flight Rules. Reglas de vuelo visual (vs IFR = instrumental). |
| **TWR** | Tower (control de torre del aeropuerto). |
| **Penacho térmico** | Columna ascendente de gases calientes desde una chimenea. Limitada en altura aeronáutica a ≤ 4,3 m/s. |

## G — Construcción

| Término | Significado |

| **Curaduría** | Curaduría Urbana. Entidad municipal que otorga licencias de construcción. |

| **LOD** | Level of Development. Nivel de detalle BIM (LOD 100 esquemático → LOD 500 as-built). |
| **Shotcrete** | Hormigón proyectado neumáticamente. Usado en sostenimiento de excavaciones y túneles. |

## H — Hidráulica y MEP

| Término | Significado |
|---|---|
| **Free-cooling** | Refrigeración aprovechando aire exterior frío (sin compresor). Rionegro >8.000 h/año disponibles. |
| **Adsorption chiller** | Chiller que produce frío a partir de calor (en vez de electricidad). Usa LiBr o NH₃. |
| **PTAR** | Planta de Tratamiento de Aguas Residuales. |
| **VRF** | Variable Refrigerant Flow. Sistema HVAC modular con refrigerante variable. |
| **DALI** | Digital Addressable Lighting Interface. Protocolo de control de iluminación. |

## I — Financiero

| Término | Significado |
|---|---|
| **CAPEX** | Capital Expenditure. Inversión inicial. |
| **OPEX** | Operational Expenditure. Gasto operativo recurrente. |
| **EBITDA** | Earnings Before Interest, Taxes, Depreciation, Amortization. Beneficio operativo cash. |
| **TIR / IRR** | Tasa Interna de Retorno. Tasa que hace VAN = 0. |
| **VAN / NPV** | Valor Actual Neto. Suma de flujos descontados. |
| **WACC** | Weighted Average Cost of Capital. Costo promedio ponderado del capital (deuda + equity). |
| **DSCR** | Debt Service Coverage Ratio. EBITDA / servicio deuda. >1,3x exigido por bancos. |
| **FID** | Final Investment Decision. Decisión final de inversión, momento que arranca el proyecto. |
| **Project finance** | Financiamiento de proyecto con garantía de los flujos del propio proyecto, no del sponsor. |
| **AACE Class 5** | Asociación de estimación de costos. Clase 5 = prefactibilidad ±50% precisión. |
