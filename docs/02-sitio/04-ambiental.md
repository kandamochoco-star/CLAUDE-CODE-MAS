# 04 — Componente ambiental

## Autoridades

- **ANLA** (Autoridad Nacional de Licencias Ambientales) — competente por superar 100 MW de generación eléctrica.
- **CORNARE** — autoridad ambiental regional, determinantes ambientales y permisos de uso de recursos (agua, vertimientos, ocupación de cauce).
- **Alcaldía Rionegro** — cumplimiento POT, licencia de construcción, gestión de residuos.

## Licenciamiento ambiental

### Licencia ANLA (Decreto 1076/2015 art. 2.2.2.3.2.2)

Aplica por:
- Construcción y operación de centrales generadoras de energía a partir de fuentes no convencionales con capacidad >100 MW.
- Posiblemente cogeneración + autogeneración a gran escala — interpretación según resolución específica.

**Etapas:**

| Etapa | Tiempo estimado |
|---|---|
| Solicitud de Términos de Referencia | 2–4 meses |
| Elaboración de **Estudio de Impacto Ambiental (EIA)** | 12–18 meses |
| Radicación + evaluación ANLA | 4–8 meses |
| Audiencia pública (probable) | +2 meses |
| **Total** | **18–30 meses** |

**Componentes del EIA:**
1. Diagnóstico ambiental de alternativas (DAA).
2. Caracterización abiótica: clima, geología, geomorfología, suelos, hidrología, hidrogeología, calidad del aire, ruido.
3. Caracterización biótica: flora, fauna, ecosistemas, áreas sensibles, conectividad ecológica.
4. Caracterización socio-económica: usos actuales, comunidades, patrimonio.
5. Identificación y evaluación de impactos.
6. Plan de Manejo Ambiental (PMA).
7. Plan de seguimiento y monitoreo.
8. Plan de contingencia.
9. Plan de cierre y abandono.

### Permisos de uso de recursos (CORNARE)

| Permiso | Aplicación |
|---|---|
| Concesión de aguas subterráneas | Captación aljibe |
| Concesión de aguas superficiales | Si se capta de quebrada |
| Permiso de vertimientos | Aunque sea reuso 95%, hay descarga de PTAR |
| Aprovechamiento forestal | Talado para excavación + paisajismo |
| Ocupación de cauce | Si pasa drenaje/línea por quebrada |
| Emisiones atmosféricas | Cogen + HVO (turbinas, motores) |
| Manejo de residuos peligrosos (RESPEL) | HVO, baterías, refrigerantes, electrónicos |

## Impactos clave y mitigación

| Impacto | Magnitud | Mitigación |
|---|---|---|
| Pérdida cobertura vegetal (descapote) | Media — 6,4 ha | Compensación 1:1 o más, reforestación nativa |
| Afectación humedales (si aplica) | Crítica | **Evitar**: rediseñar huella, retiros estrictos |
| Abatimiento NF en obra | Media | Recarga periférica, monitoreo pozos vecinos |
| Emisiones atmosféricas cogen + HVO | Media | DLE H₂-ready, SCR-NOx, HVO renovable, monitoreo continuo |
| Emisiones GEI operación | Alta inicial → Net-zero año 10 | PPA, electrolizadores, captura biochar/DAC |
| Ruido cogen, cooling, helipuerto | Media | Ubicación subterránea, atenuadores, helipuerto solo VFR diurno |
| Generación de residuos peligrosos | Media | Plan RESPEL, gestor autorizado |
| Presión sobre acueducto local | Baja-media | Captación pluvial + aljibe, reuso |
| Cambio paisajístico | Baja (pérgola integrada) | Diseño biofílico, fachadas vegetales |
| Atracción de fauna (aves, roedores) | Media | Plan gestión fauna, iluminación CRI bajo, sin agua expuesta |

## Compensaciones obligatorias

- **Compensación por biodiversidad** (Manual MADS 2018): factor 4–10x según ecosistema afectado. Posible **compra de predio en Reserva** o restauración cuenca alta.
- **Inversión 1% Ley 99/93** (si se capta agua de fuente natural): destinada a cuenca hidrográfica.
- **Compensación social**: programas con comunidad El Tablazo (educación, empleo, infraestructura).

## Sostenibilidad operativa

- **ISO 14001** Sistema de Gestión Ambiental certificable.
- **ISO 50001** Sistema de Gestión Energética.
- **Reporte público anual** alineado con GRI + TCFD + ISSB.
- **Compromiso net-zero** validado por SBTi (1,5 °C).
- **Biodiversidad neta positiva** en lote (rewilding 60% del área no construida con especies nativas Andinas: encenillos, sietecueros, robles, alisos).
