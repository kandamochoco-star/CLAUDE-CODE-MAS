## Distribución funcional (25.000 m²)

| Zona | m² |
|---|---|
| Heliopuerto FATO/TLOF + zonas seguridad | 1.500 |
| Cooling towers / dry-coolers (carenados, baja velocidad) | 2.500 |
| Cuartos eléctricos (inversores PV + transformador elevador) | 400 |
| Antenas, microondas, comunicaciones | 300 |
| Lucernarios spa + pool deck retráctil +3 | 300 |
| Pasarelas, mantenimiento, drenaje, captación | 1.000 |
| Pérgola PV social (cubierta club) | 4.000 |
| Campos PV principales (fija + tracker) | 15.000 |
| **Total** | **25.000** |

## Cargas estructurales

- PV fija: ~25 kg/m² (módulo + perfilería).
- Pérgola PV: ~80 kg/m² (estructura ligera + módulos + lucernarios).
- Cooling towers carenadas: 1.000 kg/m² localmente, distribuido en parrilla.
- Heliopuerto TLOF: aterrizaje 5,5 t × factor dinámico 1,5 = ~10 t puntuales.

## Drenaje pluvial y captación

- Cubiertas con pendientes 1,5% hacia red de canalones.
- 25.000 m² × 2.000 mm/año = **50.000 m³/año** captables.
- Dirigidos a tanque subterráneo 5.000 m³ + tratamiento → reuso (cooling makeup, sanitarios, riego).

## Antenas y comunicaciones

- 2 mástiles 18 m con balizamiento aeronáutico.
- DAS 5G outdoor.
- Microondas backup hacia POPs Medellín (en caso de corte fibra).
- Antena VHF/UHF para coordinación TWR JMC desde heliopuerto.

## Acceso a cubierta

- Solo personal técnico autorizado + huéspedes a heliopuerto/pool deck.
- Núcleo N1 con biometría adicional.
- Línea de vida + arnés en zonas de mantenimiento.

## Mantenimiento PV

- 2 robots autónomos de limpieza microfibra rotativa (sin agua).
- Inspección con dron cuatrimotor cada mes (térmica + visible) — operación coordinada con Aerocivil.
- Análisis IA degradación + detección hot-spots.

## Seguridad

- Anti-deslumbramiento certificado (módulos baja reflectancia < 1%).
- Anti-incendio CC (rapid shutdown, arc fault).
- Pararrayos tipo I + malla de tierra densa.
- Drone-detection + sistema de respuesta no letal (jamming RF) — coordinado con Mindefensa para autorización.

## Heliopuerto resumido

- FATO 24×24 m, TLOF Ø 15 m / 5,5 t.
- VFR diurno y nocturno.
- Sectores aproximación E-W (vientos dominantes).
- Hangar no contemplado (operación punto a punto).
- Coordinación obligatoria con TWR JMC.
